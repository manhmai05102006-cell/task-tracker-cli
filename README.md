
# Task Tracker CLI - Java

A simple command-line application for managing tasks,
built with Java.

## Project URL

https://github.com/manhmai05102006-cell/task-tracker-cli-java

## Features

- Add tasks
- Update tasks
- Delete tasks
- Mark tasks as in-progress
- Mark tasks as done
- List all tasks
- Filter tasks by status

## Technologies

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File I/O
- JSON

## Task Status

- todo
- in-progress
- done
